# Contributing to Homelab Agent

Thank you for your interest in contributing to Homelab Agent! This document provides guidelines for contributing.

## How to Contribute

### Reporting Issues

1. Check if the issue already exists
2. Create a new issue with:
   - Clear description
   - Steps to reproduce
   - Expected vs actual behavior
   - Your environment details

### Suggesting Features

1. Open a GitHub Discussion or Issue
2. Describe the feature and use case
3. Explain how it would benefit users

### Submitting Code

1. Fork the repository
2. Create a feature branch: `git checkout -b feature/my-feature`
3. Make your changes
4. Test thoroughly
5. Commit with clear messages
6. Push to your fork
7. Open a Pull Request

## Development Guidelines

### Command Files

When creating or modifying commands:

- Use clear, descriptive names
- Include comprehensive instructions
- Provide example output
- Document all arguments
- Test with various scenarios

### Documentation

- Keep README.md updated
- Update COMMANDS.md for new features
- Include examples where helpful
- Check spelling and grammar

### Code Style

- Use consistent markdown formatting
- Include proper headers
- Use tables for structured data
- Keep lines reasonable length

## Testing

Before submitting:

1. Test command with Claude Code
2. Verify all arguments work
3. Check output formatting
4. Test edge cases

## Pull Request Process

1. Update documentation
2. Describe changes clearly
3. Reference related issues
4. Wait for review

## Questions?

Open a Discussion on GitHub or reach out to maintainers.

Thank you for contributing! 🏠
